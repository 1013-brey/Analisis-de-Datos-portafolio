# Portafolio de Análisis de Datos & Business Intelligence

¡Bienvenido a mi portafolio profesional de análisis de datos! En este repositorio presento proyectos aplicados que abarcan modelado financiero, desarrollo de dashboards ejecutivos, econometría y analítica web, utilizando tecnologías como **Python, SQL, Power BI, Looker Studio y Excel**.

---

## Estructura del Portafolio

### 1. [Simulación Financiera y Proyecciones en Python](./01_Simulacion_Financiera_Python)
* **Objetivo:** Simulación de escenarios de inversión, cálculo de retornos netos y proyecciones de activos bajo gestión (AUM).
* **Tecnologías:** Python (Lógica algorítmica y simulación).
* **Entregables:** Scripts de simulación Monte Carlo, modelos de rendimiento neto y proyección de AUM.

---

### 2. [Dashboard Comercial Ejecutivo (Power BI & SQL)](./02_Dashboard_Comercial_PowerBI_SQL)
* **Objetivo:** Modelado relacional de datos de ventas, consultas analíticas en SQL y creación de un tablero interactivo para toma de decisiones comerciales.
* **Tecnologías:** SQL, Power BI, DAX.
* **Entregables:** Esquema de base de datos (`.sql`) y reporte ejecutivo interactivo (`.pbix`).

---

### 3. [Análisis Estadístico & Econometría Aplicada](./03_Analisis_Estadistico_Econometria)
* **Objetivo:** Evaluación de relaciones econométricas, estimación de regresiones lineales y análisis descriptivo cuantitativo.
* **Tecnologías:** Python (Modelado estadístico nativo), Excel (Análisis exploratorio).
* **Entregables:** Modelo de regresión econométrica (`.py`) y archivo de análisis descriptivo (`.xlsx`).

---

### 4. [Analítica Web & Métricas Digitales (GA4 & Looker Studio)](./04_Web_Analytics_Looker_GA4)
* **Objetivo:** Monitoreo de embudos de conversión, tráfico web, eventos de usuario y KPIs digitales.
* **Tecnologías:** Google Analytics 4 (GA4), Looker Studio, Power BI.
* **Entregables:** Reportes de rendimiento web y tablero de visualización analítica (`.pbix`).

---

## Stack Tecnológico
* **Lenguajes:** Python, SQL
* **Herramientas de BI & Visualización:** Power BI, Looker Studio, Excel Avanzado
* **Módulos & Entornos:** Lógica de programación en Python, Consultas relacionales en SQL, Modelado DAX
* **Control de Versiones:** Git, GitHub
